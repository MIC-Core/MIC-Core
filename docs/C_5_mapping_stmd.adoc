Mapping of MIC Simulation Task Extension to SSP Traceability STMD Format

=== Purpose 

==== Administrative Data

[cols="1>m,2^e,7<",width="70%",align="center",frame="topbot",options="header"]
|===
| MIC Sim. Task Name| STMD Mapping | Obligation | Short Explanation
| Specific Product Name | administrative.specific-product.name | Mandatory |The Specific product name is the unique master name of the specific product
| Ordering Project Name |administrative.ordering-project.name | Mandatory |The Ordering project name is the unique master name of the ordering development project 
| Simulation request name | administrative.simulation-request.name | Mandatory |The Simulation request name is the unique name of the simulation request
|Simulation task name | administrative.simulation-task.name | Mandatory |The Simulation task name is the unique name of the simulation task
| Overall product name | administrative.overall-product.name | Recommended |The Overall product name is the unique master name of the overall product 
| Specific Product Name | administrative.specific-product.name | Recommended |The Specific product name is the unique master name of the specific product within the company
| Simulation task confidentiality level | administrative.simulation-task.confidentiality | Recommended |The Simulation task confidentiality level is a  classification with respect to the access to contained information.
| Predicted simulation start date | administrative.simulation-task.date.start | Recommended |The Predicted simulation start date is the date at which all information will have been provided so that the simulation service can start.
|===
